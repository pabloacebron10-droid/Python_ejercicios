# Ejercicios de clase - Python

Repositorio con los ejercicios y prácticas realizados en clase durante el aprendizaje de **Python**.

## 📚 Contenido

En este repositorio se encuentran diferentes ejercicios relacionados con los conceptos vistos en clase, como:

* Variables y tipos de datos
* Operadores
* Condicionales
* Bucles
* Funciones
* Listas y otras estructuras de datos
* Entrada y salida de datos
* Ejercicios prácticos de programación


## 🐍 Requisitos

Para ejecutar los ejercicios es necesario tener instalado **Python 3**.

Puedes comprobar la versión instalada con:

```bash
python --version
```

## ▶️ Ejecución

Para ejecutar un ejercicio desde Git Bash:

```bash
python nombre_del_ejercicio.py
```

Por ejemplo:

```bash
python ejercicio1.py
```

## 🎯 Objetivo

El objetivo de este repositorio es practicar y reforzar los conocimientos de programación en Python mediante diferentes ejercicios realizados durante las clases.
